动画怎么用（傻瓜版）

一句话：它把一次操作一行代码一帧地演给你看——可以慢放、可以退回去、可以停在任意一步慢慢想。
这份指南照着做就行，不用记任何东西。

0 · 三个地方都能看动画（是同一个播放器，读法完全一样）

你在哪怎么打开
首页 →「动画学习」自己挑「章节 + 结构 + 操作」，想看什么看什么。最好用，推荐从这里开始。
首页 →「课堂」讲解页上有「演示」按钮，点一下当场把这一步演出来。
首页 →「课程问答」问完问题，回答下面会出现「看动画演示」，点它。

1 · 生成第一个动画：四步，30 秒

1在左边「章节」里选一章 —— 比如 树与二叉树

2「结构」里选一个结构 —— 还是 树与二叉树

3「操作」里挑一个操作 —— 比如 中序线索化

4点「生成动画」

下面那个 initialData 参数框不用管，里面已经填好教材的例子了，直接点生成就行。
懒得挑？切到「一句话描述」，写「看看折半查找每次怎么缩小范围」，再点「让模型选一个演示」。

2 · 屏幕上每一块是干嘛的

角标是什么怎么用
①章节 / 结构 / 操作三个下拉框，决定"看什么"。选完最后一个就能生成。
②生成动画选好就点它。旁边出现「计算中」是正常的，等一下。
③动画标题这次演的是哪个操作（「二叉树层序遍历」）。
④正在执行的那行代码整份指南最重要的一行：一行代码演一帧，所以它一直在变。看不懂画面时先读它。
⑤关键信息胶囊此刻的关键值：「当前结点 B」「当前下标 1」「q C,D」「pushed D」…… 看它就知道"现在在动谁"。
⑥面板这个算法用到的数据结构，一块一块分开画：已访问 / 队列 / 树（或 栈 / 距离 / 矩阵 / 图）。哪块在变，这一步动的就是它。
⑦播放按键上一步 ｜ 播放 / 暂停 ｜ 下一步 ｜ 回到起点。
⑧进度6 / 15 = 现在是第 6 步，一共 15 步；还没开始时写「起点 / 共 15 步」。
⑨详细 / 精简两档粒度，见第 4 节。
⑩速度0.5× / 1× / 2× / 4×，看不清就调慢。
⑪步骤条一格一步。点哪一格就跳到哪一步；鼠标停在格子上会显示"那一步做了什么"。
键盘更快：先点一下画面，然后 ← → 翻步、空格 播放 / 暂停。

3 · 画面怎么读（记住这四条就够了）

1. 顶上那行大字 = 正在执行的那一行代码。一行演一帧，和"单步调试"一模一样。

2. 灰色小胶囊 = 这一刻的关键信息：当前结点是谁、下标在哪、比较了几次、交换了几次。看胶囊就知道"现在在动谁"。

3. 灰底的大面板 = 这个算法用到的数据结构。除了树 / 图本身，还有辅助的「已访问」「栈」「队列」「距离」「矩阵」——哪块在变，这一步动的就是它。

4. 结点颜色：变黑 = 正在处理它；变灰（淡下去） = 已经处理完了；虚线空框 = 这个位置本来就没有东西，不是画错了。

4 ·「详细」和「精简」什么时候用

档位它是什么什么时候用
详细（默认）一行代码一帧，最细想搞清楚"到底哪一行做了什么"
精简每个阶段只留一帧先看整体流程，再切回「详细」抠细节
有的操作两档看起来一样（比如冒泡排序、二叉排序树查找）——因为它本来就是"一帧一步"，没有可压缩的中间过程。

5 · 想换一组数据自己试

参数框里照下面的格式改就行。逗号必须是英文逗号 ,（中文逗号会报错）。

参数怎么写例子
一列数逗号隔开49,38,65,97
一棵树按层序写，空位置写 null["A","B","C",null,"E"]
一个图JSON：顶点 + 边{"nodes":["A","B","C"],"edges":[["A","B",1]]}

每个参数框的右边都用灰字写了提示（如 1,2,3 / 如 [[1,5,9],[2,6,8]] / JSON），照着填不会错。

6 · 出问题了照着做

屏幕上出现什么意思怎么办
「参数不合理」+ 比如「第 3 个元素 "" 不是有效数字」 数据写法不对。最常见三种：用了中文逗号、多打了一个逗号、某一段是空的 按弹窗说的"第几个元素"去改
「还缺参数：initialData」 参数框被清空了 换个操作再换回来，会自动填上教材例子
「这个演示暂时无法生成」 这个操作还没有动画 换一个操作，或者去课堂 / 问答里问
「参数不足，这里用的是引擎内置的标准教学示例，不是教材原例。」 这个操作没配教材参数，用的是内置示例 不影响观看，只是一句说明
点了「下一步」画面不动 这一步本身就只有结果（比如"初始化"） 画面下方会写「这一步只有结果，没有中间过程」，继续点「下一步」
太快看不清 / 想重看 — 速度调 0.5×；或点「回到起点」重放；或点步骤条上的那一格

7 · 上课的时候怎么用

老师：讲解页点「演示」，当场把这一步演出来；想换个例子讲，点「去动画实验室」，那边可以随便换数据和操作。

学生：先跟着老师走一遍，再自己去「动画实验室」把同一个操作换一组数据跑一次，对比一下结论还成不成立。

留下产出：实验室右下角有一个「写下你观察到的规律」的框，写完点「保存观察」——这是这节课的产出，别空着。

8 · 一页速查

我想……怎么做
从头看一遍「回到起点」→「播放」（或点 空格）
在某一步反复看点步骤条上的那一格跳过去；鼠标停在格子上会显示这一步在做什么
只看大流程切到「精简」
搞懂"这一行代码干了啥"看顶上那行大字（代码）+ 它下面那行灰胶囊（当前是谁、下标多少）
换一组数据改参数框：英文逗号 / 数组 / JSON
看不懂某一块面板面板左上角就是它的名字：已访问 / 栈 / 队列 / 距离 / 矩阵 / 树 / 图
知道现在演到哪了看右下角 6 / 15，或在步骤条上看亮到第几格
