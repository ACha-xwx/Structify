## 集中待确认

1. 实际线上版本、镜像摘要、域名路由和部署状态；Compose 只证明部署意图，不证明线上环境。
2. 生产代码沙箱供应商、持久管理员配置和 504 根因；本地记录不能外推生产。
3. 新成员无私有教材时是否需要专门公开演示资源包；现有测试 fixture 不等同完整产品演示数据。
4. 模型供应商当前可用模型、费用、凭据注入与账号配额；不在仓库静态审计中发真实请求。
5. 数据恢复演练结果、RPO/RTO 与现有迁移在每个环境的应用情况；无实验不承诺数值。
6. 统一格式化和静态检查策略：前端已有 typecheck，但未确认仓库统一 lint/format 工具。
