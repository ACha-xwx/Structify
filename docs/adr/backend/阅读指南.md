## 证据标准

正文区别源码事实、设计意图和分析推论；替代方案是追溯分析，不伪造历史选型实验。源码链接是当前工作区证据，可能含尚未提交改动。列出的测试是验证入口，不代表本次已运行。完整历史对话尚未逐轮读取，因此本目录不能声称覆盖所有近期设计决策。

要继续深化检索、题库与权限等专项，应先补齐相应源码、失败用例和真实对话证据，再形成独立 ADR，不能只把旧摘要拉长。
