# 测试与验证

唯一命令映射来源是 [verify-studyroom.mjs](../scripts/verify-studyroom.mjs)，CI 来源是 [ci.yml](../.github/workflows/ci.yml)。以下命令均在仓库根执行；本次文档审计未运行构建、服务或功能测试。

```powershell
node scripts/verify-studyroom.mjs --scope backend
node scripts/verify-studyroom.mjs --scope frontend
node scripts/verify-studyroom.mjs --scope contracts
node scripts/verify-studyroom.mjs --scope architecture
node scripts/verify-studyroom.mjs --scope e2e
node --test scripts/verify-studyroom.test.mjs
```

backend 调用 Spring Wrapper test；frontend 运行 Vitest 与含类型检查的生产构建；contracts 校验 HTTP fixtures；architecture 执行 StudyroomArchitectureTest 和 FragmentContractTest；e2e 运行 Playwright。all 按 runner 顺序运行并在首个失败处停止，不表示其他未执行检查已通过。

## 隔离与副作用

测试可能下载依赖、写 target/dist/test-results 并启动进程。Playwright 配置启动 8893 后端 harness 和 5183 Vite，禁止复用已有服务；[启动器](../frontend/e2e/start-backend.mjs) 使用 test,harness profiles。[harness 配置](../backend/spring/src/test/resources/application-harness.yml) 使用内存 H2；确定性替身位于 Spring 测试目录。普通回归不得接真实模型或开发文件数据库。

本地需已安装 Playwright 浏览器；`PLAYWRIGHT_CHANNEL` 可选择已安装浏览器。CI 明确安装 Chromium。本次不执行安装或浏览器测试，也不据旧验证报告宣称当前通过。

## 未被统一 runner 替代的检查

根 `npm test` 运行 Node 布局与核心兼容回归。CI 另外有 frontend-layout、frontend-build-artifact、git diff --check、Spring package 和 Docker image 构建。更完整命令应读 CI，不把学习室 runner 当成全部项目回归。

前端目录可用 `npm run typecheck`；`npm run build` 已包含 vue-tsc。当前 frontend/package.json 没有 lint/format 脚本，本次审计未确认统一格式化工具，不编造 `npm run lint` 或自动格式化命令。

## 修改后的选择
