# Structify 试用任务卡（学生版）

> 目的：帮我们找出**我们想不到的问题**。你不需要懂技术，只要按下面的步骤操作，并把**不对劲的地方**记下来。
> 时间：大约 40–60 分钟。做得越细，帮我们越多。
> 最重要的一条：**能重复出现的问题最有价值**（每次这样做都会出问题 → 一定告诉我们是哪几步）。

## 开始之前

- 网址：`https://structify.cn`（用给你的账号登录）
- 准备：手机 + 电脑各一台（如果有），能截图就截图
- 遇到任何不对的地方，**不要反复刷新就算了**，先记下来再继续

---

## A 组｜课堂（最重要，约 20 分钟）

选一节**有课件**的课（例如绪论），点"开始"，一步一步走。

- [ ] 1. 每翻一页，**看左边讲的内容，是不是右边屏幕上那一页**。
      对不上就记：第几步、屏幕上的页码、左边讲的第一句话。
- [ ] 2. 同一个问题**故意答错 3 次**：看它会不会卡住、会不会自己跳过、会不会突然换话题。
- [ ] 3. 答对之后**连续点 5 次"继续"**：有没有跳页、空屏、或者两步内容一样。
- [ ] 4. **中途退出再进来**：是否接着上次的进度。
- [ ] 5. 手机**竖屏、横屏**各走 5 步：课件和讲稿还对得上吗。
- [ ] 6. 提问时**粘贴一段很长的文字**（比如 2000 字）：会不会报错。
- [ ] 7. 上课过程中**刷新页面**：会话还在吗。

## B 组｜动画实验室（约 15 分钟）

- [ ] 1. 用"一句话"描述这 5 个演示，记下**系统给的是不是你要的**：
      单链表逆置 / 二叉树层序遍历 / 快速排序的分区 / 拓扑排序 / 折半查找
- [ ] 2. 故意问**跟当前章节无关**的演示（例如在"栈与队列"里问折半查找）：它怎么回答？
- [ ] 3. 参数给**极端值**：只有一个元素的数组、10 个元素完全倒序、空树。
- [ ] 4. **连点下一步**、拖进度条、频繁切倍速：有没有错帧、卡死、画面乱掉。
- [ ] 5. 请回答一个问题：**这个动画你看得懂吗？** 如果看不懂，是**哪一步**看不懂。

## C 组｜课程问答（约 15 分钟）

- [ ] 1. 问一个教材里**有答案**的问题，点一下引用，看能不能定位到资料。
- [ ] 2. 打开"**深度思考**"，问一个复杂问题：思考过程和正式回答是分开的吗？有没有卡住不结束？
- [ ] 3. **上传 1 张图片 + 1 个代码文件**（都小于 8MB）：能解析吗？
- [ ] 4. 生成过程中点"**停止**"，再点"**重试**"：会不会重复、丢内容。
- [ ] 5. 把一条**已发出的消息改一下再发**：历史记录对不对。
- [ ] 6. 侧边栏分别试一次**重命名 / 置顶 / 删除**，然后刷新：还在吗？
- [ ] 7. 把界面**切成英文再切回来**：有没有没翻译的地方。

## D 组｜C 编辑器（约 10 分钟）

- [ ] 1. 从示例库按"**章节 → 知识点**"选一个程序，跑起来。
- [ ] 2. 写一段**故意编译不过**的代码：报错提示能说清是**哪一行**吗？
- [ ] 3. **粘贴一大段代码**（500 行以上）：编辑器会不会卡。
- [ ] 4. 用一次**导入**、一次**导出**：内容有没有丢。
- [ ] 5. 在聊天里点代码块的"**导入到编辑器**"：代码一致吗。

## E 组｜账号与网络（约 10 分钟）

- [ ] 1. **没登录**直接打开 课件 / 课堂 / 动画 页面：能不能被拦住。
- [ ] 2. **两个浏览器同时登录同一个账号**上课：进度会不会互相覆盖。
- [ ] 3. **快速登录 / 登出 10 次**：有没有报错或被限流。
- [ ] 4. **断网 10 秒**再恢复：页面能自己恢复吗（刷新后正常吗）。
- [ ] 5. 用**手机浏览器**（iOS Safari 和安卓 Chrome 各一次）走一遍主要页面：有没有排版错乱、字太小看不清。

## F 组｜夜间模式与中英文（约 10 分钟）

- [ ] 1. 逐页切换**夜间 / 日间**：记下**哪一页、哪个元素**看不清（截图 + 页面名）。
- [ ] 2. **中英各走一遍**：记下没翻译、或者中英文混在一起的地方。
- [ ] 3. 夜间模式下重点看**课堂 / 动画 / 聊天**三页：正文对比度、按钮文字、代码块配色。

## 记录模板（每人一份，一条一行）

| 时间 | 我在哪一页 / 哪一步 | 我做了什么 | 我期望发生 | 实际发生 | 截图 | 每次都会 / 偶尔 / 只一次 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

**填写要求**

- 一条问题写一行，**不要把几个问题写在同一行**；
- "实际发生"尽量写**原话 / 原样**，比如直接抄屏幕上的文字；
- "**每次都会 / 偶尔 / 只一次**"这一栏最关键，请一定填；
- 有截图就贴，没有就用文字描述你看到了什么。

**如果某个操作直接把页面弄坏了**（白屏、转圈不停、必须重开）：标一个 **【严重】**，优先发出来。
