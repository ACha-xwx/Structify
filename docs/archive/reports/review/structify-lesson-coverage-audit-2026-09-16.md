### 本轮修掉的一个真实缺陷（备课失败）

真实浏览器验收暴露出：模型偶尔在 `steps[].type` 写出词表外取值（大写或同义词），`ClassroomScriptParser` 直接抛错，整节课备课失败，界面上只显示"模型修正后仍未通过校验"。三处修复：

1. `ClassroomScriptParser` 在**校验前**把 `type`、`role` 两个受控字段去空白并转小写——词表外的值仍会被拒绝，不会被猜成别的类型。
2. 报错信息带上实际取值（`当前值为 "…"`），使自动修复轮能真正改对，而不是反复试错。
3. `ClassroomPreparation` 的提示词显式列出五个合法 `type` 值并禁止自造类型。

新增/改写单元测试：`ClassroomScriptParserTest#normalizesCasingOfClosedVocabularyFieldsButStillRejectsUnknownValues`。真实浏览器实测该课时因此从"备课失败"变为可正常授课，且首段讲解直接使用教材第 40 页原文措辞（"关系线性化，结点顺序存"）。

## 4. 重要发现：既有 29 个"已核验页"是改写稿，已隔离

上一轮交接与既有清单声称 8 个选段 / 29 页"已对照原始教材 PDF 核验"。逐页复核后确认**这些正文不是原书文字**：

| 证据 | 内容 |
|---|---|
| 教材第 15 页 | 源课时文本为"对于步进循环语句，一般只需考虑循环体中语句的执行次数…"，`raw/ocr_pages.json` 同页原始 OCR 为"1.5 算法 性 能 评价 “15 / 0) x=047=0; …"，两者不一致 |
| 教材第 264 页 | 源课时文本是模型总结（"查找是数据处理中最常用的操作之一…"），原始 OCR 是"前面第 2 ~7 章 学 习 了 线性 表…" |
| 08-01 选段第 264 页 | 已导入文件的该页正文**完全为空**（0 字符） |
| 其余页 | 均为带反引号代码块、统一标点的清洗稿，无 OCR 断行与空格噪声 |

处理方式：`private/reviewed-textbook/revisions/page-revisions.json` 中把这 8 个选段记入 `quarantined`（原因码 `TEXT_IS_NOT_VERBATIM_SOURCE`），不再列入 `import-manifest.json`。装载器据此拒绝加载，启动日志逐条打印拒绝原因：

```text
WARN Textbook lesson kept unpublished: 01-04-绪论-算法的时间性能分析-已核验页15-16.md -> NOT_LISTED_IN_IMPORT_MANIFEST
... （共 8 条）
INFO Loaded 5 manifest-approved textbook lessons into 27 knowledge chunks; published chunk count 24 -> 27
```

因此课堂可用课时由"8 条改写稿"变为"5 条按原文核验的整课"。这是**数量下降、正确性上升**的有意取舍：宁可少，不可把改写稿当教材事实。

这 29 页需要重新按 PDF 逐页重录才能回到课堂；它们仍保留在私有目录中，可逐页替换。

## 5. 导入安全修复（代码）

### 5.1 页级清单闸门

新增 `KnowledgeImportManifest`，`KnowledgeCorpusLoader` 由"按文件名收集整份文件"改为"按清单逐页放行"：

| 校验 | 失败原因码 |
|---|---|
| 文件必须在 `import-manifest.json` 的 `accepted` 中列出 | `NOT_LISTED_IN_IMPORT_MANIFEST` |
| 文件 SHA-256 必须等于清单 `targetSha256` | `TARGET_HASH_MISMATCH` |
| 每个 `### 教材页 N（PDF页 M）` 块必须带 `> OCR质量：已对照原始教材 PDF 核验（` 标签 | `PAGE_N_LABEL_NOT_REVIEWED` |
| 页号集合必须与清单完全一致 | `PAGE_SET_MISMATCH` |
| 每页声明的 PDF 页必须与清单一致 | `PAGE_N_PDF_PAGE_MISMATCH` |
| 清单必须声明已核验页码范围 | `MANIFEST_PAGE_RANGE_MISSING` |
| 清单缺失 / 版本不支持 | `IMPORT_MANIFEST_MISSING` / `IMPORT_MANIFEST_UNUSABLE` |

失败即整份文件不产出片段（fail closed），并通过 `KnowledgeCorpusStats.rejections` 与启动日志显式报告，不静默跳过。`app.knowledge.auto-publish-local` 现在只表示"允许从本机清单核验过的目录装载"，**不再能绕过校验**。

### 5.2 其它修复

| 问题 | 修复 |
|---|---|
| 课时 id 只由 `source_path` 派生，跨章同名文件会撞 id | `ClassroomPreparation.id()` 改为 `sha256(chapterId + "\n" + source)` |
| `lessons()` 用 `MIN(page_label)` 聚合页码 | 装载器让同课所有片段共用清单里的一个页码范围，`MIN()` 结果确定且唯一 |
| 模型为未实现算法编造动画请求 | 备课提示词明确要求：外部排序、多路归并、Dijkstra、AVL、B 树等未实现算法必须省略 `animationRef` |
| 导入会整表替换 `textbook/%` | 启动日志新增 `published chunk count A -> B`，任何缩减都可见 |
