# 项目概览

审计基线：2026-10-24 当前工作区，包含尚未提交改动；不是已发布版本证明。

Structify 将数据结构学习中的讲解、教材证据、原始课件、过程动画和代码实验整合到学习工作台。主要读者是学生；管理功能面向有相应角色的维护人员。项目定位来自仓库 package.json、Vue 用户/管理路由及 Spring 业务包，实际部署的用户规模和教学成效待确认。

## 核心概念

- 大纲草稿与修订：确认前可审核和修改的学习范围，保留历史。
- 运行（run）：一次确认后的生成与学习上下文；旧 run 不能覆盖当前 run。
- 知识点与片段（fragment）：导航层级与独立生成/发布粒度，不等同于旧 UNIT 生成任务。
- 资源与证据：课件、代码、动画及知识片段；模型只选择服务端授权候选。
- 就绪与学完：生成可读内容不是学生完成学习，两类状态分别维护。
- 调用账本：记录模型调用意图、结果与用量；不确定调用不能盲目重放。

## 能力边界

当前核心是审核大纲→冻结片段→有界准备→验证发布。保留其他模块的聊天、资源、动画和编译能力；不能因学习室替换删除 Node 兼容模块。向量检索、OCR 增强及跨环境向量库迁移在现有讨论中仍属提议，不能当作已实施功能。

系统可能连接模型供应商、SMTP 和代码执行服务；课程素材来自配置的本地/挂载目录。并非所有本地运行都需要这些服务，但真实生成与实验需要对应依赖。整体关系见[系统架构](系统架构.md)，不能从接口或环境变量存在推断服务当前可用。
