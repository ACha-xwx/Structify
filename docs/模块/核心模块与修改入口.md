# 核心模块与修改入口

本页按修改任务导航，不为每个包建立同质空文档。所有 Java 包均位于 `backend/spring/src/main/java/com/feng/dsagent/`，测试在对应 `src/test/java`。

## 学习室：大纲、任务与发布

职责是把审核范围转成可恢复、受预算限制的教学内容；不负责授予任意资源权限或把模型声明变成权威状态。入口为 studyroom/draft/OutlineController，协调在 OutlineService，计划在 fragment/ContentPlanCompiler，调度在 PreparationScheduler，模型调用在 generation/GenerationCallService，发布在 FragmentPublicationService。

修改教学计划时先看冻结计划与 requiredKinds；修改并发时检查 JdbcGenerationRepository、租约与修订；修改输出格式需同步 FragmentOutputContract、Validator、OpenAPI 与 fixtures。重点测试为 ReviewedOutlineWorkflowTest、ContentPlanCompilerTest、FragmentExecutionBudgetIntegrationTest、FragmentPublicationServiceTest 和 StudyroomArchitectureTest。

追问在 studyroom/questions，事件在 studyroom/events，测验在 studyroom/checks，讲稿在 studyroom/teaching。它们依赖已发布内容和绑定资源，不应偷偷启动另一条不受预算管理的生成链。

## 资源与检索

knowledge 提供知识片段和检索，presentation 提供课件能力，resource 提供资源模块；FragmentResourceResolver 将这些候选收束为单次生成上下文。输入是问题、章节和冻结目标，输出是 evidence/candidate 短键集合与资源指纹。资源不存在或必需类型缺失时应失败，不能为让页面通过而用无关资源替代。

查错配先跟踪检索过滤、资源 selector 和绑定结果；不要先换模型。修改检索后至少覆盖 KnowledgeSearchService 相关测试及 FragmentResourceResolverTest、StudyroomResourceSelectorTest。测试位置可通过源码名称在测试树搜索；不在此复制可能快速变化的测试数量。

## 模型与额度

model 包处理模型协议，modelconfig 管配置，aiquota 管用户额度，generation 管工作流调用与修订预算。用户额度不是 fragment 预算；管理员配置不是课程资料的授权来源。变更需考虑调用失败仍消耗 tokens、响应丢失和同 phase 复用，不能只验证成功路径。

## 编译、动画与界面

compiler 包有 CompilerController、CodeSessionController 等入口，维护执行配置、超时和输入输出限制；animation 包调用确定性 DSVP 引擎，backend/dsvp 为 Node 子进程实现。不要把模型虚构的运行输出视为执行记录。

Vue 的 user、admin、shared 分别承载用户功能、管理功能与共享设施；路由统一在 frontend/src/router，课堂页在 user/views/StudyroomView.vue。页面改动不应重定义服务端资源权限与生成状态。测试含相邻 *.spec.ts 与 frontend/e2e；构建和类型检查见[验证指南](../测试与验证.md)。

## 共享边界

auth/security 是认证与授权入口；不要在业务 Controller 临时绕过它们。chat、classroom、learning 等既有包仍服务其他产品能力，删除前追踪调用；Node 兼容服务同样不能因学习室重构直接移除。
