# D. 限制课堂事件订阅并隔离连接与生成生命周期

## Context（背景）

原订阅路径为每个连接启动虚拟线程并持续读取持久事件，没有显式活动连接准入。连接仍占用事件读取、数据库访问和内存；虚拟线程不会消除这些成本。差异可以证明资源控制原先缺失，但不能证明当时发生过连接耗尽事故。具体容量目标及触发事故待确认。

## Decision（决策）

课堂 SSE 订阅先取得许可，再读取事件：当前进程全局最多 64 个、同用户最多 4 个。完成、超时、错误及退出路径释放许可，释放必须幂等。连接只读取已提交状态；断开订阅不得取消生成任务或启动新的模型调用。上限属于进程内限制，不代表集群全局配额。

## Considered Options（考虑过的方案）

原代码的无显式准入订阅是可确认的旧实现；新代码采用全局与用户两级许可。没有证据证明当时评估过其他方案。事后分析的可能替代方案：仅限制用户不能约束整体连接数；仅限制总量不能防止单用户占满；分布式准入可跨实例计数，但需要额外协调与失败策略。以上不是历史选型记录。

## Consequences（影响与约束）

正面：限制单用户和实例的订阅占用；关闭路径统一处理，避免重复释放许可。

代价：正常多标签页或多设备也可能被拒绝；每个实例分别计数，横向扩容会改变系统总上限。

新增约束：新增退出分支必须释放许可；连接清理不能改变业务任务状态。测试需覆盖上限、失败释放与重复关闭。

风险与后续：64/4 无已确认容量依据；需验证高并发下轮询负担、重连退避和多实例行为。
