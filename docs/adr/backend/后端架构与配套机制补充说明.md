## 原记录 0001：服务边界与技术依赖

整理日期：2026-10-24

状态：已采用；依据当前仓库

### 背景与解决的问题

学习室需要权威状态和可验证的服务边界，同时其他功能仍依赖 Node。

### 决策与算法

Java 21、Spring Boot 4.1.0 负责学习室 API；JDBC 负责持久化，Flyway 管理迁移，Security/Validation 负责访问与输入约束，JSON Schema Validator 校验模型结构，ArchUnit 检查边界。保留 Node 兼容服务，禁止因学习室重构删除共享模块。

### 取舍与边界

相较继续堆叠旧 UNIT 链，此边界让服务端控制发布和权限；代价是维护两套服务及明确 API 差异。版本以 pom.xml 为准，不代表技术选型当时有完整横向评测。

### 依据

[依据文档](../../../backend/spring/pom.xml)。这是对现有材料的追溯整理；未找到证据的候选方案不追认为当时已批准。


## 原记录 0002：审核大纲与冻结片段流水线

整理日期：2026-10-24

状态：已采用

### 背景与解决的问题

旧生成链将计划、生成与展示耦合，失败容易影响已可读内容。

### 决策与算法

审核大纲保留 revision；确认前编译冻结 fragments。调度器只准备当前知识点和下一知识点首片段，优先学生等待内容；resolver 绑定资源，composer 在预算内生成，validator 验证后由 publication 原子发布。生成不能直接发布，发布不能调用模型。

### 取舍与边界

支持逐片段可读与失败恢复；放弃旧 UNIT 双模式，增加计划、任务与发布状态管理。算法属于有界优先调度，不是无限预生成。

### 依据

[依据文档](../../architecture/studyroom.md)。这是对现有材料的追溯整理；未找到证据的候选方案不追认为当时已批准。


## 原记录 0003：任务租约与模型预算账本

整理日期：2026-10-24

状态：已采用；独立开发额度改动仍在工作区

### 背景与解决的问题

并发重试、旧任务回写和模型费用需要统一控制。

### 决策与算法

保留 run fencing、lease、幂等键、历史 revision 与 token accounting。服务器决定资源授权和调用预算，发布校验活动租约及当前运行。测试账号额度政策不得外推为所有生产账号无限额度。

### 取舍与边界

防止旧 run 覆盖当前内容及重复计费；租约恢复与幂等结果存储增加复杂度。

## 原记录 0005：持久事件流与异步追问

整理日期：2026-10-24

状态：已采用

### 背景与解决的问题

刷新或 SSE 重连不应触发新的付费调用，追问失败不应破坏课程。

### 决策与算法

事件与快照游标同事务提交；SSE 只读已提交状态。追问 POST 返回 202 和幂等回执，冻结 run/fragment/revision/context，独立 FOLLOWUP 任务优先级 400；最多两次模型调用、20000 tokens、120 秒活动预算。事件负载上限 16 KiB，回放批次 100，终态事件保留 24 小时。

### 取舍与边界

支持断线恢复和失败隔离；需要事件清理与快照持久化。

### 依据

[依据文档](../../architecture/studyroom.md)。这是对现有材料的追溯整理；未找到证据的候选方案不追认为当时已批准。


## 原记录 0006：服务端测验与题库补足

整理日期：2026-10-24

状态：当前工作区采用；未据此宣称已发布

### 背景与解决的问题

测验答案暴露、题目不足和生成失败会影响教学可靠性。

### 决策与算法

优先精确题库绑定，再用有界 CHECK 任务补足；仅三个不同且受支持的单选题形成 ready 集合。CHECK 为一次调用、10000-token 预算；无效可选题不能拒绝有效课程。答案和解析冻结，普通读取提交前隐藏，教师追问由服务端提供。

### 取舍与边界

保障判题权威性，答题与浏览完成独立；缺失或坏题需重试，V44 已应用则保留，不能回滚删表重置数据。

### 依据

## 原记录 0007：确定性顺序讲稿编译

整理日期：2026-10-24

状态：已采用

### 背景与解决的问题

逐次生成讲稿增加费用并可能引用不存在的行或动画帧。

### 决策与算法

服务端从已发布 fragment、现有资源、真实代码行数、确定性动画帧说明和显式幻灯片区域编译讲稿，不调用模型。区域写入需认证、run/revision fence 与几何验证，每 revision 最多十二个区域；V43 保留删除墓碑。

### 取舍与边界

引用可校验且无额外模型成本；自动 OCR 和云端语音不属于当前实现。

## 原记录 0008：课程投影与软删除

整理日期：2026-10-24

状态：已采用

### 背景与解决的问题

个人课程管理不能损坏草稿历史和生成账目。

### 决策与算法

用户课程读取认证投影；名称和用户活动与大纲正文及后台发布时间分开存储。删除在用户锁内软删除，撤销排队/运行任务租约、取消 run 并清空 current-run 指针；保留 revisions 和 token accounting。手工大纲修改同步生成历史 revision，不调用模型。

### 取舍与边界

支持审计并阻止删除后回写；需要所有读写路径遵守软删除和所有权检查。

## 原记录 0009：本地代码沙箱与 HTTP 协议

整理日期：2026-10-24

状态：本地验证采用；线上 504 根因未确定

### 背景与解决的问题

本地 Java 请求遇到 400，代码运行还可能编译失败或超时。

### 决策与算法

Piston 独立容器仅发布 loopback；Spring 网关明确 HTTP/1.1，测试拒绝 h2c Upgrade。编译错误、运行错误及上游超时分类返回。当前诊断卷曾改用容器 GCC 8.3，元数据仍标 10.2，不能声称 GCC 10.2 验证通过。

### 取舍与边界

本地链路验证可重复；privileged 沙箱需要部署隔离。线上纯文本 504 与本地结构化超时不同，仍需线上配置和日志。

### 依据

[依据文档](../../archive/operations/local-code-sandbox.md)。这是对现有材料的追溯整理；未找到证据的候选方案不追认为当时已批准。
