## 2026-09-19 课堂问答回归课件主线：提问不占页、大模型判答、答错必须重答

- **背景（用户要求）**："按 PPT 讲解做得很好，但希望保留之前的问答环节，问题可以出自大模型/教材/PPT，并让大模型判断回答是否正确；如果不正确要重新回答，而不是直接课程结束。" 改成"课件为骨架"后脊线契约要求"每页恰好一个讲解步骤"，模型**不再被允许生成 `question` 步骤**——问答在课件课上整体消失；判答也只会改变状态，答对答错都会在"下一步"被消耗掉，提问若落在最后一步就会**直接课程结束**。
- **提问回到课件主线**（`ClassroomPreparation`）：`spineInstruction` 现要求**每段至少 1 个、最多 `questionLimit(页数)=min(4, max(1, 页数/3))` 个 `type=question` 步骤**，且必须**紧跟它所提问的那一页**（`slideRefs` 与 `slideScope` 都沿用那一页 → 屏幕停在原页），不能放在本段第一个步骤；整段 0 提问直接判契约不合法并触发重试，避免问答再次静默消失。校验从"第 n 步 = 第 n 页"放宽为**教学步按页推进（`pageCursor`）、提问步不消耗页**，因此"课件顺序就是讲解顺序"的承诺对每个教学步依然成立。
- **问题来源可标注**：question 步骤新增 `questionSource ∈ {model, textbook, slide}`——`model` 老师针对该页设计、`textbook` 取该页教材片段里的例题/习题/思考题、`slide` 该页本身就是练习/例题页；提示词给了三种取法的写法，`ClassroomScriptParser` 校值并把非法取值回显（错误信息带实际值，便于修正轮修好）。前端在提问时显示"老师出题 / 教材出题 / 课件出题"。无课件课时（第 4、10 章）走原教材路径，那里本来就有 1 个可判定问题。
- **判答闸门（关键语义改动，`ClassroomTimeline`）**：ANSWER 判为 `MISCONCEPTION|INCORRECT` 时**不再推进**——状态回到 `WAITING`、`answered=false`、`attempts+1`、响应带 `retry:true`，学生必须**重新作答**；`CONTINUE` 遇到未答对的题只会清掉上一次作答并**停在原步，不越过、更不会结束课程**（旧行为：错答也置 `answered=true`，下一次"下一步"直接消耗该步，提问在末步时整课结束）。判答提示词改为"指出偏离在哪并给能自己纠正的提示，不要把答案念出来，也不要说本课结束；`attempt>1` 时提示要更具体"。
- **前端**（`ClassroomView.vue`）：用 `questionOpen / failedAttempt / interruption / canType / canAnswer` 取代原 `waiting` 单一判定。答错时**保留输入框**、主按钮变"再答一次"、**不出现"下一步"**，并显示"这次回答还不正确（第 N 次），请重新回答这个问题。"；提问打断仍走"回到课堂"；提问步骤显示来源标签。
- **验证**：后端 `mvn -o test` **376 项全绿**（classroom 包 43 项，含新增 3 项闸门回归：答错留在同题、未答对不能越过、**末步答错不结束课程**；parser 新增 `questionSource` 值域校验；备课新增 1 项"重试轮次的步骤不得并入最终脚本"与 1 项题源判定）；前端 **40 文件 / 204 用例全绿**、`vue-tsc --noEmit` 通过。真机 `scripts/verify-slide-spine.mjs`：**08-02 二叉排序树 26/26 页课件顺序保持**（6 个提问、2 个教材延伸步、0 重复页）、**02-03 单链表 36/36 ×2 轮**均保持，提问步逐题作答、练习页题源标为 `slide`（详见下方实测记录）。
- **修复"重试轮次的步骤被并进课堂"（页面整段重复的真因）**：`ClassroomModelJson.generate` 的自修复循环**最多调用校验回调 3 次**，而 `ClassroomPreparation` 把收集步骤的 `partSteps` 建在回调之外——被拒那一轮已经写进去的步骤没有清空，接受那一轮再追加一次，于是**同一段页面在脚本里出现两三遍**。08-02（26 页 → 3 段）第一段两轮被判错（尾步带了 `slideRefs`，撞"延伸步骤不能引用课件页"），最终脚本因此有 **50 个页面步 / 只有 26 个不同页**，页序校验报"s027 重复、第 13 页应为 s039"。改为**每轮校验从空数组开始、只有整轮通过才交付**（`AtomicReference` 承接），并补回归测试：模拟"先被拒 3 步、再接受 3 步"，发布出来的 `stepCount` 必须是 3 而不是 6。
- **段末收束步合法化**：分段只是上下文长度的产物，模型每段都会想收一句尾，之前提示词写"本段不加延伸步骤"而代码只拦"带页引用"的尾部步骤，导致白烧两轮重试。现在非末段**允许至多 1 个收束步**（`type=summary`、不写 `slideRefs`、`slideScope` 沿用本段最后一页，`maximumSteps` 相应 +1），提示词同时要求**不要出现"本段""这节课结束了"这类生成过程用语**——实测产出的收束步已写成"我们学习了……"而不再是"本段我们学习了"。

- **`scripts/verify-slide-spine.mjs` 同步**：页面顺序改为**按页推进去重**后再比对（提问步复用当前页，不再被当成多出来的页面）；新增"提问步必须停留在它提问的那一页"断言；作答内容取该步自带的教材证据，连续 3 次被判错即报错终止并打印服务器理由，重答次数一并统计，避免"悄悄少走几步"被误读成计划缺口。

## 2026-09-18 教学主线反转：课件为基准、教材退为 RAG 知识库

- **方向（用户拍板）**："把课件作为上课的基准，教材作为背后的知识库"——课件页决定讲解顺序与内容边界，教材退为按需检索的知识源，用来精准锁定定义、算法与例题。确认的三项取舍：① 教材例题/推导保留为**延伸步骤**（不单独占页，右栏沿用当前页）；② 左栏讲稿以课件页为主线、教材 RAG 补深度并标注出处；③ 先做**确定性版本**，不依赖模型额度即可预览。
- **可行性实测**：课件每页正文中位 113 字（p75 207）——足以当锚点、不足以供深度；每课时课件页数中位 **15**（p75 18，max 30），与课堂原约 19 步同量级，故"一页一步"可直接沿用现有推进节奏；53/57 课时有课件，缺的正是 04-01/02/03 与 10-01。
- **教材片段改为按页切分**（`KnowledgeCorpusLoader`）：`page_label` 由"整课时范围"变为 `第 N 页`，chunkId 由 `source#page#part` 生成；此前 `ORDER BY id` 实为哈希乱序、页码无法定位。重导入后 **536 段 / 10 章**。
- **小节即范围**：`KnowledgeText`（抽出共用分词/打分）、`TextbookSections`（识别正文小节行、书页眉 `1.1　标题　· 3 ·`、`*8.3.3` 选学小节）、`LessonPassageIndex.evidence(section, query, limit)` 逐级放宽：**精确小节 → 上级小节 → 整课**，再按词元重叠排序。
- **课件骨架**：`SlideSpinePlan` 按"细分课时 → 场景 → 页面"逐页生成步骤（页↔步 1:1，步骤自带 `slideScope`/`slideRefs`/`slideMatch`/`sourcePages`/`textbookMatch`）；教材中的例题若该小节没有任何练习类课件页，则补一个**延伸步骤**（≤4、不写 `slideRefs`、沿用前一页 scope）。`ClassroomPreparation` 有课件即走此路径，`app.classroom.slide-narration=model`（默认，模型按页改写讲稿）| `deterministic`（本地组装、**不发模型调用**）；无课件课时保持原教材驱动路径。两条路径共用同一套"教材依据等级"（`SlideSpinePlan.textbookMatch`），模型写的步骤也必须回报，否则左栏教材出处会静默消失；生效模式在启动日志里打印一行 `Classroom slide narration mode = …`，配置静默失效时一眼可见。
- **页面清单与顺序（2026-09-19 重写）**：`PresentationCatalog.slidesForCoursewareKey` 不再按"场景"拼页（那会把别的 deck 的"上次课回顾"串进来并打乱顺序）。新规则：`slides.json` 每页自带 `lessonIds`，**认领页最多的 deck 就是这节课的 PPT**，页面按该 deck 天然页序（slideNumber 升序）输出，跨 deck 串场页一律丢弃；没有任何 deck 认领的课时（01-08、06-05~08、09-06）退回场景序计划但按（deck 序、页号）重排。场景值改为**从页面自身推导**（`ClassroomPreparation.sceneOf`：回顾→intro、小结/总结/谢谢→summary、练习/例题→practice、其余→concept），`slideScope` 校验表与脊线同源。连带修复 `planIds` 只认 A/B 后缀导致 **C/D 细分课时（08-04C、09-01C、01-06D 等）整体丢失**的缺陷。
- **备课分段生成**：整课一次模型调用在大课时会**截断 JSON**（36 页必现）。`ClassroomPreparation` 现按每段 12 页分段调用、逐段契约校验（"本段第 n 步讲第 n 页"），最后一段才允许延伸步骤（且延伸步骤**禁止携带 slideRefs**，否则会被当成页面步骤污染顺序）；讲稿约束明确"第 n 步只讲第 n 页，回顾页讲复习、普通页不得讲成全课总结"。
- **模型讲稿的脊线清单必须自带每页的 `slideScope` 取值**：清单只给 `[小节/角色]` 的话，模型会拿幻灯片 ID 当 `subLessonId`、拿小节当 `scene`，整课被契约校验拒掉并烧掉 3 轮重试。
- **summary 不是结束**：`ClassroomState.SUMMARY` 既是"本步是小结"又是"课程结束"，中途的小结页（跨细分课时时很常见）曾把会话锁死在"本课已经结束"，后续课件页全部不可达。现在**只有游标越过最后一步才算结束**（后端 `ClassroomTimeline.apply` 与前端 `finished` 同步改为看游标）。
