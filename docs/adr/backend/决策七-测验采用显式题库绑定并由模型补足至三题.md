# G. 测验采用显式题库绑定并由模型补足至三题

- Status：Proposed
- Date：2026-10-24（补录日期，原始批准日期待确认）
- Related commits / pull requests：805fbbb 提交三题与 AI fallback 设计；题库及服务实现未提交。
- Relation：Amends [决策一-智能体计划与资源权限](决策一-智能体计划与资源权限.md)；补充其边界，不替代或废止原记录。Proposed 的补充规则尚未获得正式接受。

## Context（背景）

当前设计要求知识点测验形成三题集合；单靠生成可能不足或无效，外部题库又需要明确知识点绑定。已发布题目还必须对应具体内容修订。三题的教学理由、题库审核制度以及题库故障是否应该阻断或告警，均不能由实现自动推得。

## Decision（决策）

服务端读取配置的显式题库绑定，优先选择允许审核状态的单选题；不足时调用模型生成候选补足。以去除首尾空白后的题干做精确去重，只有恰好三题形成有效集合。准备任务发布前复核租约与内容 revision，并发布已组合集合，不在该阶段再次读取题库改变结果。答案与解析随发布保存，不把外部题库的后续修改直接投影为已发布答案。

## Considered Options（考虑过的方案）

805fbbb 的设计变更可确认从旧描述向“三题并允许 AI 补足”演进；未发现选型试验。事后分析的可能替代方案：纯模型出题、仅题库出题或语义匹配题库，分别涉及生成依赖、覆盖不足和错绑风险；不声称当时实际评估。

## Consequences（影响与约束）

正面：明确区分权威候选和模型补足，发布集合受内容修订约束。

代价：需维护绑定与审核；三题约束可能让已有一两道好题的集合仍无法就绪；文本去重不能发现语义重复。

新增约束：题库缺失、畸形、题量不足、内容变更和租约失效均需测试；私有题库不得入库。

风险与后续：当前题库异常会降级为空候选，可能掩盖配置故障；V44 增加来源字段但当前发布 INSERT 未见写入，不能声称来源链已完成。
