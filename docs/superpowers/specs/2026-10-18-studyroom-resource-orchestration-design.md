# 课程问答按教学目标编排资源

日期：2026-10-18。状态：方案范围已获用户认可，本文待审阅。

## 目标与范围

第一期同时解决三个问题：每步固定资源入口及内容冗余；单张 PPT 无法覆盖知识点、密集页面阅读困难；AI 很少为实现类步骤选择 C 代码。保留现有课堂、消息、权限、授权证据与资源白名单。

第二期才考虑自动讲述、区域高亮、动画与讲解同步、动作播放游标及打断恢复。本期不引入完整课堂播放器，不要求每堂课包含全部资源类型，不自动生成未经审核的代码。

## 依据

当前 StudyroomView.vue 固定呈现三类入口，activeResource 只取当前类型第一个可用资源，入口计数却汇总整堂课。StudyroomGraph 在生成步骤前依据原问题筛选候选，PPT/动画/C 代码上限分别为 12/8/4；提示词要求每步最多一个资源。StudyroomResourceCatalog 按章节筛选代码目录，加载失败会记录警告后继续。

上述为代码事实，不等于已证明某次请求漏选代码的具体原因。实施前用可复现请求确认候选、模型选择和校验各阶段结果。

借鉴本地 G:/Code/OpenMAIC/components/stage/scene-renderer.tsx 的场景分发和 packages/@openmaic/dsl/src/action.ts 的内容/动作分离。本期只采用按教学目标组织呈现的原则，不宣称复刻其播放能力。

## 用户体验

每步包含明确教学目标与简洁讲解。默认一个主展示场景，允许没有外部资源；确需对照的补充材料通过具体名称入口打开。取消固定 PPT、动画、C 三类常驻标签和空资源占位。计数只描述当前步骤实际材料。

一个场景可包含多张相关 PPT。页码表示本步页集合的位置，并另标原始课件页码；提供前后翻页及缩略图目录。逐页讲解随选页更新，步骤总说明保留但不重复全文。默认完整显示原图，提供缩放、拖动、全屏及恢复整页；移动端提供同等可触达控件。

代码分为只读讲解与编辑实验。讲解聚焦已有示例的相关片段，完整源码可展开；实验必须有任务、初始代码、标准输入与预期观察，只有输出确定时才给出精确预期结果。通过现有远程沙箱运行，不在服务器直接执行学生代码。

切换步骤时恢复本次页面会话中该步骤的页位置及编辑草稿；刷新后恢复已保存的当前步骤，页位置和代码草稿的跨刷新持久化不属于本期。翻页不代表掌握，也不自动推进步骤。

## 生成链路与职责

1. 问题理解与步骤规划：结合授权证据确定教学目标、步骤意图和资源需求，不要求先选资源 ID。保留现有生成长度预算与配额机制。
2. 每步资源检索：使用原问题、章节、步骤目标、算法及操作检索。课件、动画、代码均经过现有访问控制；不以取消章节或授权约束来扩大覆盖。
3. 绑定与校验：从授权候选中选主场景及必要补充材料，验证 ID、参数、页归属和代码片段边界，去重并保留使用目的。相关页面组成有序集合，不机械附上整套课件。
4. 围绕材料生成讲解：讲解对应选定页面、动画或代码；没有合适材料时返回明确的纯讲解步骤。
5. 持久化与呈现：只保存通过校验的结果，前端按场景呈现，不自行补资源。开发模拟资源也应通过同一后端目录和绑定流程。

上述是职责划分，不要求每个职责都单独调用模型。候选检索和规则校验使用确定性代码；具体模型调用合并方式在实施计划中根据现有客户端预算确定，不以增加调用数量作为目标。补充步骤采用同一编排链路。

## C 资源选择规则

概念步骤无需代码；实现、递归及实现相关操作优先检索代码；修改、调试、边界验证步骤优先选择实验。不得强制每堂课出现代码。

代码按步骤独立排序并去重，避免整堂课共用前四个样例造成覆盖不足。检索文本纳入算法、操作和样例用途，检查章节 ID 与课件键映射。候选数量保持有界，具体预算在实施计划中确定并通过覆盖用例验证。

在存在直接相关且授权的代码示例时，实现类步骤应绑定代码；无法绑定时记录原因，不允许静默用无关样例替代。实验相关运行配置只影响能否运行，不影响可授权源码的阅读和绑定。

## 数据契约与兼容

新增编排契约版本，与现有课堂用于并发控制的 version 字段区分。步骤包含教学目标、意图、主场景和补充引用；课件场景包含有序页引用及逐页讲解；代码场景包含已有样例引用、讲解/实验方式和任务数据。资源标题、访问地址和可用性由服务端解析，不信任模型提供的元数据。

资源参数继续服从各类型白名单，不把 PPT 页列表塞入动画 parameters。旧版 steps/resources 经适配器转换为可展示场景；旧记录不重新调用模型或擅自添加材料。支持旧版单资源与已有多资源记录，无效引用按不可用状态处理。数据库变更使用新增 Flyway 迁移，保留已有数据。

当前追问携带步骤目标、选中资源/页和代码方式；代码运行结果作为带来源的上下文数据，不作为系统指令。普通追问留在当前步骤，确有新教学目标时追加补充步骤，不重写其他已保存步骤。

## 失败处理与诊断

无候选返回纯讲解；目录异常与正常无匹配分别记录。非法或越权引用不能交付前端；移除后同步修正依赖该资源的讲解，避免留下“如图所示”等悬空指代。图像或动画加载失败可重试，并保留文字和其他已授权材料。运行服务未配置时明确提示，仍允许查看代码。

切换步骤、翻页或切换材料时保护异步请求，旧响应不得覆盖新选择。编辑草稿按步骤和资源隔离。

结构化诊断关联请求 ID、步骤 ID、候选数量、选中 ID、选择/排除原因和校验结果。区分无匹配、目录失败、候选截断、模型未选和校验移除；不把推断当作已确认原因，不记录密钥或完整私有材料。

## 验收与验证

- 纯概念问题：可生成纯讲解或相关课件，不产生空入口或强制代码。
- 跨页知识点：一学习步骤可连续阅读多页相关 PPT，页序、原始页码和逐页讲解对应，切页不丢步骤说明。
- 页面阅读：完整显示不裁切，放大拖动后能恢复整页，桌面和窄屏可操作。
- 实现类问题：在固定授权目录含对应代码时，为先序遍历递归实现、队列入队等步骤绑定正确示例，而非只保证出现任意代码。
- 宽泛问题：步骤规划后仍能根据具体子目标检索到相关代码。
- 实验问题：任务、初始代码、输入与观察目的齐全；沙箱配置失败和程序错误分别呈现。
- 冗余控制：无固定三类入口；补充引用有明确用途；同一材料复用不同页或片段时不复制资源实体。
- 兼容及边界：旧课堂可打开；越权引用拒绝；资源失败可重试；快速切换不串页、不串代码；补充步骤遵循同样规则。

使用确定性目录与模型响应夹具验证契约、分步检索、授权和降级；前端验证翻页、场景选择、缩放与竞态；运行后端相关测试及前端类型检查/构建。真实模型做少量同题人工验收，分别观察候选与最终绑定，不将随机生成次数当作稳定选择概率。布局和阅读能力用浏览器实际验证。
