# Structify 课堂 / 动画本地修复交接

更新：2026-09-16。仅适用于 `ACha-xwx/Structify`，不是旧 Node/HTML 项目。

## 已对齐的主流程

```text
数据库教材片段（textbook 来源、VERIFIED、允许课堂使用）
  └─ GET /api/v1/classroom/lessons
      └─ POST /api/v1/classroom/preparations
          ├─ 后台模型生成整课 JSON
          ├─ 结构 / 引用 / 动画请求校验 → 字段错误反馈模型，最多 3 次
          └─ GET /api/v1/classroom/preparations/{id}
              └─ ready：DRAFT 教案 + 当前用户课堂会话
                  ├─ CONTINUE：用户手动前进一步
                  ├─ ANSWER：模型语义判断，展示老师反馈
                  ├─ ASK：先回答插问，下一次 CONTINUE 显式恢复主线
                  └─ animationRef：本地 DSVP 模拟 → 逐步状态 → Vue 算法舞台
```

原有已发布课堂脚本接口继续支持。新生成教案不会自动对全体用户发布。
学生看到的步骤去除参考答案字段；课时游标、老师回答和会话版本持久化。
前端提交 `expectedRevision`，过期操作返回 409，不额外消耗一步。
模型返回的额外运行状态字段不能修改课堂进度。

课堂动画链接携带会话、课时、步骤及版本。前端从服务端重新读取当前会话后执行
对应 `animationRef.request`，不会从章节名猜测另一个例子。返回课堂仍使用原会话。
当前消费的是内嵌 DSVP 请求；只有字符串 / animationId 而没有请求的历史引用
尚未迁移，会明确提示不可执行，不替换成默认演示。

## 动画实现边界

状态由 Java `DsvpSimulator` 计算，不由模型编造。模型只做语义理解和结构化输入。

| 范围 | 当前计算 |
| --- | --- |
| 顺序表 / 数组 | 插入和删除逐个移动、访问、设置、交换；有序表双路归并 |
| 栈 / 队列 | 入、出、查看端点，空结构与容量检查 |
| 链表 | 逻辑节点序列的插入、删除、查找；不是完整指针内存动画 |
| 小顶堆 | 建堆、上浮、下沉、提取及中间交换状态 |
| 哈希 | 逻辑键值映射；不宣称实现某种桶布局或冲突算法 |
| 二叉树 | 含空位的层序输入；先序、中序、后序、层序遍历 |
| 图 | 按显式边计算 BFS / DFS，支持有向标记与起点 |

未实现的 Dijkstra、AVL、B 树、外部排序等不能宣称已有真实动画。
模型必须选择已实现操作，不能用无关演示替代。
逐帧状态同时保存在 `trace.steps[].state` 和 `animationData.steps[].state`；保存后的定义不再丢失堆、哈希等中间状态。旧记录如果没有快照，仍只能按旧操作解释，不能宣称已经迁移重算。
学习台使用 `/api/v1/animations/interpret` 调用模型生成请求，随后调用 simulate 进行本地计算。已移除按章节标题正则选择固定演示的分支。未支持算法由模型明确说明，不替换成无关演示。

## 接入正式数据前的必要检查

1. 确认正式教材目录。当前仓库不包含私人教材，不要把旧项目业务代码或 PPT 复制过来充当来源。
2. Spring 配置为 `app.knowledge`：`KNOWLEDGE_DIR` 指向教材目录；默认 `KNOWLEDGE_AUTO_PUBLISH_LOCAL=false`，使用数据库中审核状态符合要求的内容。
3. 既有 `auto-publish-local` 开关启用时会替换 textbook 索引并标记为 VERIFIED；这不代表做过人工审核。不要为清除“教材缺失”提示而直接开启。只应对已核验教材执行受控导入。
4. 通过现有模型设置或环境配置接入服务、Key 和额度。默认模型名为 `deepseek-v4-pro`，管理员 / 环境显式配置优先。注意：DeepSeek 官方已下线 `deepseek-v4-flash`，当前可选 `deepseek-flash` / `deepseek-v4-pro`；两者都是思考型模型，调用时必须带 `thinking:{"type":"disabled"}`（`app.model.provider=deepseek` 时客户端会自动附加），否则 JSON 模式会被思考内容挤掉。可用 `GET /models` 核对模型名后再填。凭证仅在 Git 忽略目录。
5. 应用新增 Flyway V24 迁移后测试真实账号流程：选课 → 备课 → 逐步讲解 → 回答 → 插问 → 动画 → 返回 → 刷新恢复。

模型返回片段 ID，服务器校验 ID 后直接附原文和页码，避免让模型反复誊写引文。此约束不能证明所有生成讲解均符合教材。
备课当前是在后台一次生成整课，不是逐页边看边生成；队列保存在内存，重启会丢失未完成任务。
实测二叉树选段在启动后约 28 秒首次状态检查时已生成 10 步；这不是精确耗时基准，不保证所有课时速度。暂不使用或生成 PPT。
