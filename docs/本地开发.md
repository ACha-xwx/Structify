# 本地开发

## 环境与运行前提

Java 21 来自 [pom.xml](../backend/spring/pom.xml)，前端 CI 使用 Node 22，根 package.json 声明 Node >=18；建议本地按 CI 使用 22，而不是把根最低版本当作全部依赖的兼容证明。Windows 使用 PowerShell 与 `mvnw.cmd`，CI Linux 使用 `./mvnw`。安装依赖和 Wrapper 首次运行会下载文件。

仓库根的 `npm ci` 用于 Node 兼容服务及根回归，`frontend/` 下另行 `npm ci`；二者不能互相替代。克隆地址应从当前仓库 remote 获取，不复制历史 README 的个人远端。本次未访问远端。

## 启动与确认

1. 获取源码后，在 `frontend/` 执行 `npm ci`。
2. 仓库根执行 `./scripts/start-studyroom-preview.ps1`。脚本创建 `private/dev-db`，未设置 DB_URL 时使用其中 `reviewed-outline` 文件数据库，并以 dev profile 启动 Spring。已有 DB_URL 优先，启动前检查它不会指向真实外部库。
3. 另开终端在 `frontend/` 执行 `npm run dev -- --port 5173 --strictPort`。
4. 浏览器打开 http://localhost:5173 ，后端健康入口为 http://127.0.0.1:8792/actuator/health 。健康成功只说明应用健康检查通过，不等同于课程生成成功。
5. 用原终端 Ctrl+C 停止。不要同时从 IDE 再启动一个连接相同文件 H2 的实例。

直接 Maven 启动与预览脚本不同：基础 application.yml 默认内存 H2；预览脚本显式设置持久 DB_URL。PowerShell Maven 属性用引号，例如 `./mvnw.cmd spring-boot:run '-Dspring-boot.run.profiles=dev'`，执行目录为 backend/spring。

## 兼容路径的额外依赖

上述步骤启动 Vue 与 Spring 核心链路。vite-routing.ts 同时把 `/api`、`/healthz`、`/presentation`、`/pdfs`、`/vendor` 指向 Node 兼容服务；使用这些功能时，需要在仓库根先 `npm ci`，再用单独终端运行 `npm run dev`。Node 运行可能写入其本地数据，配置和目录先读 [兼容服务入口](../backend/node/server.js)。不要为解决这些路径的代理错误误启动第二个 Spring。

## 配置来源与密钥

完整名称和默认值只在 [基础配置](../backend/spring/src/main/resources/application.yml)、[开发配置](../backend/spring/src/main/resources/application-dev.yml)、[生产配置](../backend/spring/src/main/resources/application-prod.yml) 维护。本文只解释用途：

- DB_URL/DB_USER/DB_PASSWORD 与 DB_DRIVER 控制连接；prod 固定 MySQL 驱动，不能照搬 H2。
- JWT_SECRET 用于认证；生产不得使用开发默认值。MODEL_PROVIDER/MODEL_BASE_URL/MODEL_NAME/MODEL_API_KEY 配置模型，dev 具有供应商与模型默认值，但密钥仍需配置，不代表默认模型当前仍可用。
- KNOWLEDGE_DIR、PRESENTATION_DIR、PRESENTATION_IMAGE_DIR 定位资料。脚本检测 `private/courseware-latest/知识库/转换清单.json` 后才自动选择该资源包；显式环境变量优先。未配置完整资料时，缺证据可能阻止片段生成，这是预期边界。
- PISTON_BASE_URL 是代码执行环境候选配置；生产可能有管理员持久配置覆盖，参见[部署与运维](部署与运维.md)中的本地代码沙箱节（历史全文 [archive/operations/local-code-sandbox.md](archive/operations/local-code-sandbox.md)）。
- SMTP_* 与 AUTH_MAIL_ENABLED 控制邮件。未配置真实邮件时，不应声称验证码已送达。
- STUDYROOM_FRAGMENT_* 是工作流预算；AI_DAILY_TOKEN_QUOTA 是用户额度，二者不是同一个限制。

开发配置含自动测试账号和开发认证默认值；这里不复制密码，禁止将 dev profile 用于生产。对话中的账号权限变更不是仓库默认部署事实。密钥使用当前运行进程环境或部署环境文件注入，不写入文档、Git、截图。不要假设项目自动读取根 `.env`，Spring 的实际加载入口需由配置和启动方式确认。

## 常见修改路径

学习室 API 从 OutlineController/FragmentController 进入；生成预算从 GenerationCallService 进入；资源错配先查 FragmentResourceResolver 和 KnowledgeSearchService；课堂页面从 frontend/src/user/views/StudyroomView.vue 进入；路由和权限从 frontend/src/router 进入。完整职责见[核心模块](模块/核心模块与修改入口.md)。

没有私有资料时，优先用测试夹具理解流程，不复制真实教材到仓库。浏览器 harness 是确定性验证环境，不是面向真实用户的演示数据服务。
